    設定

    AI 問題整理

    填入你自己的 OpenAI API key，按「✨ AI 幫我整理問題」時，網頁會直接呼叫 OpenAI。沒有 key 也能用免費的複製貼上方式。

    • ChatGPT Plus 訂閱不包含 API key。API key 要另外到 platform.openai.com 申請並預先儲值，費用和 ChatGPT 月費分開計算。
    • key 只存在你的瀏覽器，費用由你的 OpenAI 帳戶支付。
    • 你的問題會從瀏覽器直接送到 OpenAI，適用 OpenAI 的隱私政策。
    • 不要在公用電腦上選「記住在這台裝置」。
    • 請自己備份 key。清除瀏覽資料（Cookie 和網站資料）、換瀏覽器或換裝置後，這裡記住的 key 就會不見；OpenAI 的 key 建立後只會完整顯示一次，沒備份就只能重新建立。建議存在密碼管理工具，不要存在一般的記事本或聊天紀錄裡。
    保存方式

    按「測試連線」會列出你的帳戶可用的模型。
